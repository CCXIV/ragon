Обратите внимание:
путь к файлу ВСЕГДА считается от пути мода.

Может быть логическое непонимание,
когда идёт загрузка изнутри папки...
путь всё-равно считается от мода, даже изнутри папки.

//-------------------------------------------------
// ЗАГРУЗКА 
//-------------------------------------------------

Формат: список.
Каждый элемент: тоже список 
(команда;параметр;параметр;..).

//-------------------------------------------------
// ПЕРЕМЕННЫЕ
//-------------------------------------------------

Все переменные сохраняются в файле "lii_main.bean".
ДО работы загрузчика переменные читаются.
КАЖДЫЙ переход между меню сохраняет переменные.
В том числе, команда "system:reload" сохраняет переменные.

Крайне рекомендуется:
инициализировать переменные default,
чтобы первый запуск не сломался из-за ошибок.

Обязательно: 
в начале переменной ставить знак "$".
Это нужно, чтобы обрабатывать выражения.

Обратите внимание:
При присваивании переменной, её имя -- это текст.
Писать <var></var> в левой части НЕ НАДО.
(Если только это не ваша цель: вычисляемое имя, например).

Некоторые выражения (например: sub) загрузчик не поддерживает.

//-------------------------------------------------
// ВЫРАЖЕНИЯ
//-------------------------------------------------

Выражения описаны в отдельном файле.

Пример использования:

<list><text>default</text><text>mymod</text><text>omnimod</text></list>
<list><text>default</text><text>mykey</text><text>omnitexture</text></list>
<list><text>load</text><x>text{$mymod;"/";$mykey;".bean"}</x></list>

Суть примера: вычисляется имя файла (из имени мода и ключа).

//-------------------------------------------------
// КОМАНДЫ
//-------------------------------------------------

set;название переменной;значение

Присваивает значение.

//-------------------------------------------------

default;название переменной;значение

Инициализация переменной.

Присваивает значение, ТОЛЬКО если переменной не существует.
Т.е. если переменная уже существует, её значение не меняется.

//-------------------------------------------------

load;файл

Загружает следующий файл.

//-------------------------------------------------

load_set;название переменной;файл

Присваивает значение. 
Данные загружаются из файла.

//-------------------------------------------------

load_lang;файл

Загружает файл в языковой кэш.

//-------------------------------------------------

load_program;ключ;файл

Загружает программу.

//-------------------------------------------------

load_texture;ключ;файл

Загружает текстуру.

//-------------------------------------------------

load_mainatlas;ключ текстуры;файл

Загружает текстуру в главный атлас.

//-------------------------------------------------

load_atlas;ключ атласа;ключ текстуры;файл

Загружает текстуру в атлас.
(Может не работать.
Если приложение слишком простое,
в таком приложении достаточно только главного атласа).

//-------------------------------------------------

cache;ключ;файл

Загружает файл в память.
