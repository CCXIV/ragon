Выражение это список.
Записывается в обратной польской нотации.

Пример:

<x>={$a;0}</x>
<x>={$a;+{$a;1}</x>
<x>debug{text{"$a:";$a}}</x>

Расшифровка:

$a=0
$a=$a+1
debug("$a:"+$a)

//-------------------------------------------------

Обработка:
Первый символ параметра = тип.

$ 							- переменная
" 							- текст
.0123456789 				- число
всё остальное 				- выражение
если такого выражения нет 	- ошибка

ВНИМАНИЕ:
отрицательные числа образуются унарным минусом.

//-------------------------------------------------

Важно понимать:
это не язык программирования.
Парсер НЕ проверяет ошибки, НЕ делает оптимизаций и т.д.
Просто такой удобный алгоритм.

//-------------------------------------------------
// ВЫРАЖЕНИЯ
//-------------------------------------------------

sub{имя;выражение;...}

Подпрограмма.

(В некоторых случаях, например: загрузчик) НЕ СОХРАНЯЕТСЯ.
Но используется, если нужно выполнить несколько выражений.

//-------------------------------------------------

return{значение}

Выход из подпрограммы.

//-------------------------------------------------

call{имя;выражение;...}

Вызов подпрограммы.

Выражения нужны, чтобы подготовить переменные.
Все переменные глобальные.

//-------------------------------------------------

={переменная;значение}

Присвоение переменной.

//-------------------------------------------------

def{переменная;значение}

Инициализация переменной.

//-------------------------------------------------

-{значение}
+{значение;значение}
-{значение;значение}
*{значение;значение}
/{значение;значение}

Математические операции.
Результат: только число.

//-------------------------------------------------

digit{значение}

Преобразует значение в число.
Для списка\хэша: посчитает количество элементов.

//-------------------------------------------------

int{значение}

Округляет значение (и преобразует в число).
Для списка\хэша: посчитает количество элементов.

//-------------------------------------------------

text{значение;...}

Преобразует в текст.
Если подать несколько значений -- слеплит вместе (в текст).

//-------------------------------------------------

debug{значение}

Записывает значение в канал debug.
